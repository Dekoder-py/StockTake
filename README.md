# StockTake

This is an stock / inventory management application made for my Year 12 DGT assessment.

## Running it

1. Go to releases and download the latest version's .jar
2. Open your terminal to the path of the downloaded jar
3. Run `java -jar StockTake-v*.*.*.jar`

**You will need Java installed to run this!**
